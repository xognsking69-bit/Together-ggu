# Togetrip V3.20.0 — Preflight

공식 Expo SDK 57 문서 기준으로 출시 전 설정을 다시 정리한 누적본입니다.

- Expo SDK 57: Android compile/target SDK 36
- expo-notifications: ~57.0.19
- 알림은 현재 '로컬 일정 알림' 용도이며 remote background notification은 활성화하지 않음
- Android 일정 알림 채널은 앱 코드에서 생성
- production Android 빌드는 AAB
- iOS production은 EAS/App Store Connect/TestFlight 경로 사용
- 내부 지도 SDK/API key 없음. 장소는 외부 지도 앱으로 연결
- EAS projectId, Apple Team ID, App Store Connect app ID, Google service account 등 계정 생성값은 임의 입력하지 않음

실제 네이티브 빌드 성공 여부는 EAS 계정 연결 후 확인해야 합니다.
