# Togetrip 3.28.31 — 영수증 화면 및 구매 진입점 보완

기존 앱 유지. iOS 빌드 53 / Android 코드 51. 3.28.30 배포 파일과 구분되는 새 소스 버전이며 이번 변경의 빌드·스토어 업로드는 미실행.

## 반영
- 더보기의 선택형 보상 광고 제거. 보상형 광고 컴포넌트 import/렌더 및 운영 보상형 광고 ID 연결 제거. 배너는 기존 배너 광고로 유지하며 과거 배너 숨김 로컬 상태를 더 이상 참조하지 않음. AdMob의 광고 단위 자체는 삭제하지 않음.
- 영수증 AI 카드의 고정 흰색 배경을 테마 surface로 변경. 제목, 안내, 사진 선택/촬영 버튼, 빈 사진 영역, 인식 결과, 비활성 분석 버튼의 배경과 글자색을 함께 테마에 맞춤. 비활성 버튼 전체 opacity로 글자를 희미하게 만드는 동작 제거.
- 지출 추가/지출 내역 탭: 글자 12→16, 최소 높이 42→56, 여백 증가. 다크모드 비선택 탭 글자도 밝게 표시.
- 영수증 AI 10회권 카드 추가. 사진 촬영 자체는 무료이고 AI 분석 횟수 상품임을 안내. 한국어/영어/일본어/중국어 구매 안내 추가.
- 스토어의 정확한 소모성 상품·가격을 조회하는 native adapter와 구매 요청 연결 코드 추가. 구매 금액은 실제 스토어 priceString만 표시. 결제 완료만으로 로컬 횟수를 부여하지 않음.

## 10회권 판매 제한 — 실제 판매 미완료
- app.config의 receiptPurchases.enabled는 false로 고정. UI는 판매 준비 중, 결제 비활성.
- 현재 Worker의 /receipt/credits는 결제 준비 확인 정보(salesReady, paidAnalysisReady, recoveryReady, creditsPerPurchase=10, 일치하는 appUserId)를 제공하지 않으므로 환경변수만으로 결제를 열 수 없음.
- 기존 /receipt/analyze는 무료 5회 경로. 유료 분석 차감·실패 복구·결과 재전달·안전한 재설치 잔액 복구가 아직 연결되지 않음.
- 유료 원장과 webhook의 기존 서버 구현은 유지. 이번 작업에서 운영 Worker/바인딩, 스토어 상품/가격/세금·계약 설정, RevenueCat 웹훅을 변경하지 않았음.
- 양 스토어 10회 소모성 상품 등록 및 연결, 서버 유료 처리/복구, 구매 후 확인 상태 지속 저장/재실행 복구, 실기기 sandbox 검증 이후에만 출시 가능. 현재 소스를 판매 가능 완성본으로 보고하지 않음.
- 기본 가격 정책은 기존 계획의 한국 1,900원/10회이나 이번 작업에서 스토어 가격을 확정·게시하지 않았음.
