# Togetrip 3.28.31 — 화면 수정 및 10회권 검증 준비

기존 앱 유지. iOS 빌드 53 / Android 코드 51. 이번 버전의 EAS 서명 빌드·스토어 업로드는 아직 미실행. 기존 3.28.30 업로드와 구분한다.

## 화면 수정
- 더보기 선택형 보상 광고 및 배너 숨기기 연결 제거. 기본 배너 유지.
- 영수증 AI 카드·버튼·글자·인식 결과 배경을 함께 다크모드에 맞춤. 비활성 버튼의 전체 opacity 제거.
- 지출 추가/지출 내역 탭: 글자 12→16, 최소 높이 42→56.
- 기존 달력 7칸 고정 수정 유지.

## 10회권 소스 구현
- 앱: 정확한 소모성 상품/스토어 가격 확인, SDK 초기화 단일화, 서명된 영수증 세션과 같은 SDK 사용자 확인, 가격 변동 시 결제창 차단.
- 구매창 전에 기존 거래 목록과 구매 의도를 저장. 결제 응답 유실 시 새 거래만 대조하고, 확인 전 재구매 차단. 클라이언트에서 횟수 부여하지 않음. webhook으로 기록된 본인 거래만 확인.
- 서버: 무료 5회 우선. 무료만 사용하려던 요청이 다른 기기의 사용량 변경 때문에 유료로 바뀌지 않도록 명시적 유료 사용 헤더 필요.
- 유료 분석은 사진 해시/요청 ID로 원자 예약. 동일 요청은 한 번 차감, 성공 완료, 실패 반환. 중복/변조된 사진 재사용 차단.
- 유료 결과만 AES-GCM으로 사용자·요청 ID에 묶어 암호화 저장. 24시간 내 재조회 가능, 알람으로 암호문 삭제. 원장에 원본 사진·평문 영수증을 저장하지 않음.
- 15분 미완료 예약은 알람으로 한 번 반환. 앱 삭제·오프라인 상태에서도 복구되며 늦게 온 완료로 재차감하지 않음.
- 구매 잔액/거래 tombstone은 자동 만료시키지 않음. 알람은 결과 청소와 예약 반환만 수행.
- 복구코드는 서버 무작위 256비트. 서버는 해시만 보관, 앱은 SecureStore에 보관. 사용자가 앱 밖에 별도 저장한 뒤 구매 준비. 재설치/다른 기기에서 같은 이용권 계정을 복구하며 여행 데이터는 변경하지 않음. 복구 시도 IP 일일 제한/본문 제한 적용.
- 구매 및 복구 안내 한국어/영어/일본어/중국어 추가. 일부 기존 서버 오류 문구는 한국어로 표시될 수 있음.

## 판매/배포 상태
- 일반 production-ads 빌드에서 구매 기능 비활성. receipt-sandbox 프로필만 테스트 구매 UI 활성화.
- 클라이언트 SANDBOX와 서버 ledger 환경이 일치해야 함. 서버의 SANDBOX 구매 허용과 PRODUCTION 검증 완료 조건 분리.
- wrangler 설정에는 새 원장 바인딩/migration만 준비. 모든 유료 활성화 변수는 기본 false. 실제 Cloudflare 계정에 배포하거나 기존 namespace/데이터를 변경하지 않음.
- 실제 Worker migration 이력, 서버 키/환경, 스토어 상품·가격, RevenueCat 앱/상품/webhook 연결은 계정 로그인 후 확인 필요. 새 유료 API/구독 가입 안 함.
- 구매 기준은 기존 승인 범위인 한국 1,900원/10회권 하나. 실제 가격은 스토어 조회값 사용하며 상품 생성/가격 게시 미실행.
- 실제 스토어 결제 취소/지연승인/환불/Google 거래 ID 대조/기기 재설치 복구 검증 미완료. 실제 판매 완료라고 보고하지 않음.
