# Togetrip V3.14.0 — Cross-platform Maps

- iOS: 일정 장소를 Apple Maps 네이티브 URL(`maps://`)로 열고, 실패 시 Apple Maps 웹 링크로 fallback
- Android: 일정 장소를 `geo:` URI로 기본 지도 앱(일반적으로 Google Maps)에서 열고, 실패 시 Google Maps 웹 검색으로 fallback
- Web: Google Maps 검색 링크 사용
- 일정 추가 모달을 열 때 이전 장소 입력값이 남지 않도록 초기화
- 기존 일정/지출/정산/AI/공동여행/게임/꾸미기 로직 유지
- 앱 표시 버전 V3.14.0 / iOS build 2 / Android versionCode 2

이번 버전은 지도 API 키나 네이티브 지도 SDK를 추가하지 않아 기존 빌드 설정에 미치는 영향을 최소화했습니다.
앱 내부에 지도를 직접 렌더링하는 기능은 아직 포함하지 않습니다. 실제 지도 SDK 추가는 TestFlight/Google Play 기기 테스트 후 별도 단계로 진행하는 편이 안전합니다.
