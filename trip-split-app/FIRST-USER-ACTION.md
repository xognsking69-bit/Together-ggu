# 처음으로 사용자가 해야 할 단계

아직 GitHub에 중간 ZIP을 덮어쓸 필요는 없습니다.

코드/설정 측에서 계정 없이 할 수 있는 정리는 여기까지 진행했습니다.
다음 실제 단계에서는 아래 계정 정보가 필요합니다.

1. Expo(EAS) 계정 로그인
2. iOS 출시를 진행하려면 Apple Developer 유료 계정
3. Android 출시를 진행하려면 Google Play Console 개발자 계정

계정 연결 후 EAS가 실제 projectId/서명 자격증명을 생성 또는 연결해야 네이티브 빌드를 실행할 수 있습니다.
그 전까지 projectId나 스토어 ID를 임의로 파일에 넣지 않습니다.
