# Togetrip V3.13.0 — UI Redesign 1

시안의 화면 구조를 실제 기존 앱에 안전하게 1차 반영했습니다.

- 홈: 여행 히어로 카드 + 지출/정산/일정/영수증AI/지도/게임 바로가기
- 일정: 독립 탭 추가, 기존 TripCalendar와 기존 일정 데이터를 그대로 사용
- 일정/지도: 기존 장소/Apple 지도 연결 기능을 유지하면서 일정 목록 UI 추가
- 지출/정산: 기존 데이터·계산·입력 로직 유지
- 동행자: 기존 홈 동행인 관리 기능 유지
- 게임: 기존 GameZone 유지, 더보기와 홈에서 접근
- 설정/꾸미기/공동여행/백업: 기존 관리 화면 그대로 유지
- 하단 내비게이션: 홈 / 일정 / 지출 / 동행자 / 더보기 형태로 재구성
- 표시 버전: V3.13.0

중요: 지도는 아직 앱 내부 네이티브 지도 렌더링이 아니라 기존 Apple 지도 연결 방식입니다. Android용 Google 지도 연결 및 실제 기기 알림은 별도 네이티브 단계에서 검증/추가합니다.
