# Togetrip 3.28.30 — 광고 확장 소스 후보

동일한 기존 앱. iOS 빌드 52 / Android 코드 50 예정. 앱 표시·app.json·package·lock 버전 3.28.30 일치.

## 변경
- 홈에만 있던 배너를 화면 하단의 단일 슬롯으로 이동: 홈·일정·지출 목록·동행자·더보기·정산·미니게임. 한 화면에 배너를 중복 쌓지 않는다. 지출 입력/수정 폼에는 표시하지 않는다.
- 입력·이동 버튼과 간격을 두고 광고 라벨을 표시한다. 실제 슬롯 폭이 320 미만이면 고정 배너를 숨겨 가로 잘림을 피한다. 실제 좁은 화면/스크린리더/글자 확대 검증 필요.
- 더보기에서 사용자가 선택하는 보상형 광고 추가. 정상 EARNED_REWARD 이벤트에만 30분 배너 숨김, 조기 종료/로드 실패에는 지급하지 않는다. 영수증 횟수·금전 보상 없음.
- 광고는 자동 실행되지 않는다. 준비 중 이중 탭 방지, 화면 이탈 후 늦게 도착한 로드 이벤트 차단, 로드 시간 초과 처리, 닫기/오류/해제 시 리스너 및 네이티브 광고 객체 정리.
- 보상 기한은 기기에 저장해 재실행 시 복원, 30분 만료/재진입 시 배너 복귀. 저장 실패 시 현재 세션에는 보상이 적용되지만 재실행 복원은 보장되지 않는다. 로컬 시계·저장값 조작 방지 기능은 아니며 유료 잔액과 분리.
- 광고 요청 전 UMP 동의 확인, 비개인화 요청 유지, SDK 초기화 중복 방지, 최대 광고 콘텐츠 등급 G. 이 설정만으로 아동 대상 규정 충족 또는 스토어 연령 등급 변경 완료를 의미하지 않는다.
- 버튼/안내 한국어·영어·일본어·중국어 지원.

## 실제 광고 연결 차단

기존 배너 광고 ID 유지. 영상은 별도 **보상형 광고 단위** 필요:
EXPO_PUBLIC_ADMOB_ANDROID_REWARDED_ID / EXPO_PUBLIC_ADMOB_IOS_REWARDED_ID.
실제 ID가 없으면 운영 빌드에서 보상형 버튼을 숨긴다. 배너 ID를 재활용하거나 테스트 ID를 운영 대체값으로 쓰지 않는다. test 프로필에서만 Google 공식 테스트 단위를 사용한다.

보상형 형식은 영상/참여형 소재 등을 제공할 수 있어 코드만으로 모든 노출을 영상으로 보장하지 않는다. 필요 시 AdMob 광고 단위의 미디어 유형 설정을 실제 계정에서 확인한다.

AdMob 로그인 요청 시간 초과로 실제 단위 생성/미디어 설정은 미완료. Google/Apple 스토어의 광고 포함 표시·개인정보·광고 연령 설정도 이번에는 실제 계정에서 수정하지 못했다. 필요 시 사실에 맞게 수정하되 정확한 판매/광고 상태를 확인하지 않고 완료로 보고하지 않는다.

## 스토어 설정 검토 대상

- Apple: 연령 등급의 Advertising=Yes, 광고 SDK 데이터에 맞는 App Privacy, 필요한 세금/유료 앱 계약/은행 정보 상태 확인. 계약 동의·금융정보 입력은 사용자 처리.
- Google: Contains ads=Yes, Data safety와 실제 광고 SDK 데이터 일치, Target audience 설정 검토. 광고를 추가했다고 성인 전용으로 제한하지 않는다.
- 10회권 1,900원은 계속 미출시. 결제·복구·유료 분석·샌드박스 검증 완료 전 상품 판매 활성화 금지. 미제공 기능을 스토어 소개에 제공 중이라고 쓰지 않는다.
