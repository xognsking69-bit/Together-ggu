# Togetrip 스토어 등록 문구 초안

## 앱 이름
Togetrip

## 부제/짧은 설명
함께 만드는 여행 일정과 경비 정산

## 설명
Togetrip은 동행자와 여행 일정과 경비를 한곳에서 관리할 수 있도록 만든 여행 도우미입니다.

- 날짜별 여행 일정 관리
- 장소를 Apple 지도 또는 Android 지도에서 바로 확인
- 여러 통화의 여행 지출 기록
- 동행자별 공동 경비 계산과 정산
- 영수증 사진을 활용한 입력 보조
- 공동 여행방을 통한 여행 데이터 공유
- 여행 준비 체크리스트
- 여행 중 재미있게 사용할 수 있는 미니게임
- 테마 및 화면 꾸미기
- 일정 30분 전 로컬 알림

지도, 사진, 알림처럼 권한이 필요한 기능은 해당 기능을 사용할 때만 이용합니다.

## 검색 키워드 후보
여행, 여행경비, 정산, 여행일정, 동행, 경비분담, 여행준비, Togetrip

## 스크린샷 후보
1. 홈 — 여행 요약과 빠른 메뉴
2. 일정 — 캘린더와 일정
3. 지출 — 여행 경비 입력
4. 정산 — 동행자별 정산
5. 동행자 — 프로필과 동행 관리
6. 게임 — 여행 미니게임
7. 꾸미기 — 테마 설정

※ 실제 스토어 제출용 스크린샷은 TestFlight/실기기 화면을 기준으로 제작해야 합니다.
