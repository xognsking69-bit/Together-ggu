# Togetrip 출시 직전 인계 체크리스트

## 코드에서 이미 준비한 것
- 앱 버전/빌드 번호
- iOS bundle ID / Android package
- iOS 암호화 신고 기본 설정(일반 HTTPS 통신 기준)
- Android production AAB 설정
- 일정 로컬 알림 및 Android 알림 채널
- 외부 지도 연결(지도 SDK/API Key 불필요)
- Togetrip 아이콘/스플래시
- 개인정보처리방침/스토어 설명 초안
- 기존 영수증 AI / 공동여행 / 정산 / 게임 / 백업·복원 유지

## 실제 출시 전에 사용자에게 필요한 것
1. Apple Developer / Google Play Console 계정 상태 확인
2. Expo(EAS) 계정 로그인
3. 개발자 연락처 이메일 확정
4. EAS 최초 연결 시 생성되는 projectId를 프로젝트에 연결
5. iPhone TestFlight 실제 테스트
6. Google Play/App Store의 계정 소유자용 설문·약관·개인정보 공개 최종 확인

EAS projectId, Apple/Google store app ID처럼 계정에서 실제로 생성되어야 하는 값은 임의로 넣지 않았습니다.
