# Togetrip V3.28.16 무료 출시 후보

- 앱 표시 버전과 Expo 설정/패키지 버전: 3.28.16
- iOS buildNumber / Android versionCode: 36
- 영수증 AI 구매 버튼과 RevenueCat 구매 호출을 앱에서 제거했습니다.
- 영수증 AI는 게스트당 누적 무료 5회만 허용하고, Worker 전체 하루 분석은 최대 10회로 제한합니다. 한도는 UTC 날짜에 따라 초기화됩니다.
- 준비된 App Store Connect 상품과 RevenueCat Offering은 삭제하지 않았으며 이번 앱 버전에서는 판매하지 않습니다.

## 실제 배포 전 확인

1. Cloudflare에 이 커밋의 `worker/receipt-ai-worker.js`를 `wrangler.jsonc` 설정으로 배포합니다. 앱 빌드만 바꾸면 기존 서버의 결제 크레딧 경로가 그대로 남습니다.
2. EAS production 환경의 `EXPO_PUBLIC_RECEIPT_API_URL`을 실제 Worker의 `/receipt/analyze` 주소로 설정합니다. 주소가 없으면 AI 영수증 기능이 작동하지 않습니다.
3. iOS/Android 새 빌드에서 앱 표시 버전 V3.28.16과 구매 버튼 부재, 무료 5회, 6번째 요청 차단을 확인합니다.
4. 실제 영수증 인식 품질, Cloudflare 비용과 개인정보 처리방침의 연락처 및 공개 내용을 확인한 뒤 스토어 심사를 진행합니다.

이 변경은 유료 앱 계약이나 사업자등록을 완료한 것으로 간주하지 않습니다. 결제 기능은 별도 출시 버전에서 구현·검증해야 합니다.
