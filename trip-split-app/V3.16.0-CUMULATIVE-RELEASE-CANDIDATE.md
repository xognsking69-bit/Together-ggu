# Togetrip V3.16.0 누적 개발본

실제 반영:
- V3.15까지의 홈/일정/지출/정산/동행자/게임/꾸미기/공동여행/AI 기능 유지
- expo-maps 기반 앱 내부 네이티브 지도 캔버스 추가 (iOS Apple Maps / Android Google Maps)
- 기존 일정은 장소 문자열만 저장하므로 좌표 핀을 허위로 생성하지 않고 지도 검색 연결 유지
- 일정 30분 전 로컬 알림 + 알림 표시 handler + Android 알림 채널
- Togetrip 실제 아이콘 / splash / favicon / Android 아이콘 에셋 교체
- V3.16.0 / iOS build 4 / Android versionCode 4

남은 외부 조건:
- Android 앱 내부 Google 지도는 Google Maps SDK for Android API key 설정이 필요합니다.
- expo-maps는 Expo Go에서 사용할 수 없으므로 development/TestFlight/production build에서 검증해야 합니다.
- 일정 장소를 지도 핀으로 정확히 표시하려면 주소/장소명을 위경도로 바꾸는 geocoding 단계가 추가로 필요합니다.
- 스토어 심사 통과 자체는 코드만으로 보장할 수 없습니다.
